# 0009: The paint brush is the only labelling tool; terra-draw stays only for the AOI rectangle
- **Status:** Accepted (Gage, 2026-10-26)
- **Context:** Gage (2026-10-26) wants a paint brush in place of polygon drawing, and AlphaEarth is never hand-labelled. Labels are painted on local imagery and can train an AlphaEarth model (spec 005), so no polygon labelling is left.
- terra-draw 1.38.0 draws vectors only. Its `terra-draw.ts` (tag `terra-draw@1.38.0`) exports `TerraDrawRectangleMode`, which spec 002 uses for its AOI. It starts in a built-in `"static"` mode, and `setMode` stops the old mode before starting the new one.
- maplibre-gl 6.16.0 (`src/ui/handler/mouse.ts`, `handler_manager.ts`, `keyboard.ts`): mouse pan is the left button without Ctrl; rotate is the right button or Ctrl+left. `dragPan` wraps mouse and touch pan together.
- Mouse handlers listen for `mousedown` on the canvas container. The keyboard handler binds only `=`/`+`, `-` and the arrow keys. `transform.isPointOnMapSurface` tells whether a screen point is on the globe.
- **Decision:** The brush is hand-rolled in `map/`, adds no dependency, and labels local imagery only. Polygon labelling is deleted with its code: `TerraDrawPolygonMode`, `TerraDrawSelectMode`, `checkRing` and its validations, `toPixelPolygons`, `samplePixels`, `PixelPolygon`.
- terra-draw stays for spec 002's AOI rectangle, in `"static"` mode except while the AOI tool is active, when the brush is in Pan. In Paint mode, `map/` keeps mouse and pen `mousedown` from MapLibre rather than calling `dragPan.disable()`, which would also stop touch pan, and disables `dragRotate`, `doubleClickZoom` and `boxZoom`.
- **Consequences:** No dependency is added or removed. ADR 0003 is partly superseded: terra-draw holds for the AOI rectangle, but its ±180° polygon consequence lapses, as an AOI across 180° spans two UTM zones and `aoiGrid` refuses it. ADR 0004's block on vertices beyond `MAX_LAT` lapses too.
- Spec 001 criteria 2, 3, 5 and 13-15, and the polygon parts of 8 and 12, are superseded (spec 003). Brush code must normalize longitude. Dropping terra-draw later would mean hand-rolling the rectangle.
