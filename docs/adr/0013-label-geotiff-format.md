# 0013: Label GeoTIFF: 0 = unlabelled, class table in GDAL_METADATA

**Status:** Accepted (Gage, 2026-10-26), with spec 004.

**Context:** Spec 004 saves and loads labels (deferred in spec 003; ADR 0010 left the format open) and imports class rasters from other tools. Label values are 1..255 and 0 is unlabelled (spec 003), so a 255th class collides with ADR 0001's fixed GDAL_NODATA "255". Class names must travel in the file. Checked 2026-10-26: in geotiff 3.0.5 (`src/geotiffimage.js`), `getGDALMetadata()` is async and returns the dataset-level `Item`s of the GDAL_METADATA tag (42112) as raw inner text. It doesn't unescape XML entities (xml-utils `find-tag-by-name` slices the string). `getGDALNoData()` parses GDAL_NODATA (42113), and 8-bit unsigned data reads as `Uint8Array`. GDAL's GTiff driver (stable docs, 3.13) keeps non-standard metadata items in that tag and band nodata in 42113. RATs go to `.aux.xml` by default (in-tag RATs only from 3.12). Options: (a) a single-band Uint8 GeoTIFF with a class-table item; (b) a JSON file of sparse tiles, which GIS tools can't open; (c) a GeoTIFF plus a required sidecar JSON, which is two files to keep together.

**Decision:** (a). ADR 0001's writer gains two parameters: the GDAL_NODATA string ("255" for classifications, as before, and "0" for labels) and an optional GDAL_METADATA string written as one more IFD tag. Label exports cover the imagery's whole grid and copy its tags. They carry one dataset item, `GEOAPP_CLASSES`: an XML-escaped JSON array of `{ value, name, colour }`. Imports accept any single-band 8-bit GeoTIFF, resampled by nearest pixel centre, honour its GDAL_NODATA if set, and are masked by the imagery's nodata (spec 004). A sidecar class map of the same shape is optional.

**Consequences:** No new dependency, and tile sizes stay fixed. Labels round-trip byte for byte, since no path labels imagery nodata (specs 003, 004), and GIS tools show unlabelled pixels as transparent. Uncompressed full-grid files cost width x height bytes even when sparse (classic-TIFF limit, ADR 0001); compression can come later. `core/` escapes on write and unescapes on read. QGIS won't show the names, since they aren't a RAT; writing one is a later option. 16-bit class rasters are refused for now.
