# 004: Seed labels from a classified GeoTIFF or a model

**Goal:** Fill spec 003's label store on the open imagery, never on imagery nodata, from a classified GeoTIFF or from a model run on that imagery, merged with or replacing existing labels, so the user corrects it with the brush, exports it as a label GeoTIFF that imports back unchanged, and retrains.

**Status:** Approved (Gage, 2026-10-26). Build order: after spec 003, before spec 005. **ADRs:** 0013 label GeoTIFF format (Accepted; amends 0001); uses 0002; external models are ADR 0012's. **Build clarifications (2026-10-27, awaiting Gage):** the "Settled in build" rule and the words it adds to criteria 9, 12, 16 and 17.

**Decided (Gage, 2026-10-26)**, besides what Scope and Rules state: the 256-tile cap stays in v1 (an OPFS store or view-only seeding can follow); spec 001's classification export doesn't write the class table.

## Scope
In: "Import labels" (a classified GeoTIFF plus an optional class-map JSON) resampled onto the imagery grid; "Seed from model" with "Min. confidence"; Merge or Replace; masking by imagery nodata; editing seeds with the brush; "Export labels" as a GeoTIFF on the imagery grid that imports back to the same labels and classes; Train as in spec 003.
Out: external model files, ONNX and GPU inference (ADR 0012, spec 006); multi-band, 16-bit or float class rasters; CRSs outside ADR 0002; other resampling (e.g. majority); matching classes other than by exact name; seeding or labelling AlphaEarth; `.aux.xml` sidecars, RATs and QGIS styles; a TIFF colour map in the export; raising `MAX_LABEL_TILES`; undo.

## Interfaces (`core/`)
```ts
const CLASS_ITEM = "GEOAPP_CLASSES"; // GDAL_METADATA dataset item (ADR 0013)
type ClassEntry = { value: number; name: string; colour?: string }; // value: source pixel value 0..255; colour "#rrggbb"
seedWindows(dst: Grid, src: Grid): Window[] // dst tileWindows with a pixel centre on src; row-major; may over-include, never misses
sourceCells(dst: Grid, src: Grid, w: Window): Int32Array // per pixel of w, row-major: col, row of the src pixel holding its centre, or -1, -1
gatherCells(cells: Int32Array, sw: Window, data: Uint8Array, out: Int16Array): void // out[i] = data at cell i if inside src window sw; else untouched (caller fills -1)
markValues(vals: Int16Array, seen: Uint8Array): void            // seen (256 entries)[v] = 1 for every v >= 0
classesFromValues(seen: Uint8Array, nodata: number | null): ClassEntry[] // ascending, nodata skipped, name "Class v"
parseClasses(json: unknown, nodata: number | null): ClassEntry[] // throws Error naming the bad field
mergeClasses(list: LabelClass[], incoming: { name: string; colour?: string }[]): { list: LabelClass[]; values: number[] } | "too many"
  // list, then incoming names not in it (exact match), in order; values[i] = label value of incoming[i];
  // missing colours from the palette by final position; > 255 -> "too many"
seedLut(entries: ClassEntry[], values: number[]): Uint8Array    // 256 entries: entries[i].value -> values[i]; unlisted -> 0
applyLut(vals: Int16Array, lut: Uint8Array): Uint8Array         // -1 -> 0
maskNodata(tile: Tile, labels: Uint8Array): void                // labels[i] = 0 where any band equals tile.nodata or is NaN
seedFromModel(model: Model, tile: Tile, minProb: number, values: number[]): Uint8Array // values[argmax] where max softmax >= minProb, else 0; nodata -> 0
mergeTile(old: Uint8Array | undefined, seed: Uint8Array): Uint8Array // old where old > 0, else seed
putTile(store: LabelStore, w: Window, labels: Uint8Array): "ok" | "full" // replaces w's tile; all-zero deletes it; "full" changes nothing
encodeClasses(classes: LabelClass[]): string // `<GDALMetadata><Item name="GEOAPP_CLASSES">` + XML-escaped JSON ClassEntry[] (value = index + 1)
decodeClasses(inner: string): unknown       // unescapes &amp; &lt; &gt; &quot; &apos;, then JSON.parse; throws on bad JSON
```

**Rules.**
- **Enabling.** Import labels and Export labels need local imagery open; Seed from model also needs a model (trained, or loaded and validated as in spec 001 against the imagery's band count; spec 005 adds the source check). While seeding runs, the brush, Train, Import labels, Seed and Export labels are disabled; while spec 003's paint queue is non-empty, Import labels and Seed are.
- **Import labels** takes a GeoTIFF and optionally a class-map JSON (`ClassEntry[]`). A file that isn't single-band 8-bit unsigned (AlphaEarth files included) is refused with "Label files must be single-band 8-bit GeoTIFFs."; its CRS and extent must pass spec 001's raster-open checks, with their messages. `nodata` is the file's GDAL_NODATA if an integer 0..255, else null, so an untagged file reads every value as a class.
- **Classes.** The table is the class map if given, else the file's `CLASS_ITEM` (`decodeClasses` of geotiff.js `getGDALMetadata()[CLASS_ITEM]`), else `classesFromValues` of the values at the sampled cells (a first pass). `parseClasses` applies spec 003's name rule and rejects 0 or over 255 entries, duplicate values and the nodata value; on error ui shows "The class table is invalid: <field>." Colours come from the entry, else spec 003's palette by position. Nodata values, unlisted values and pixels whose centre is off the file stay unlabelled. Names are edited afterwards in spec 003's list, with no prompt.
- **Resampling** is by nearest pixel centre: imagery pixel (c, r)'s centre (c + 0.5, r + 0.5) goes through the imagery's gt, `core/crs` and the inverse of the file's gt, and is floored (spec 005's transfer at k = 1). Both paths then apply `maskNodata` with the imagery (spec 001's rule over all bands), so no stored label is ever on imagery nodata.
- **Tiling.** Import visits each window of `seedWindows(imagery, file)` once per pass (two passes when classes come from values; the first reads no imagery). For each, `io/` reads, one at a time, only the file's 256x256 windows (aligned to the file's grid) that hold one of its cells, then the imagery window once if any gathered label is non-zero. At most one file or imagery window is held at a time, besides the label stores.
- **Seed from model.** "Min. confidence" is a number field, 0 to 1, step 0.05, default 0; a value outside 0..1 disables Seed and shows "Min. confidence must be between 0 and 1." Seeding reads every imagery window once and applies `seedFromModel` (`predictTile`'s logits and argmax, first maximum), then `maskNodata`. The incoming classes are `model.classes`, without colours.
- **Merge or Replace.** While any pixel is labelled, "Seed mode" offers Merge (the default) and Replace; otherwise it is disabled and seeding replaces with no confirm. Merge fills only unlabelled pixels, with `mergeClasses(list, incoming)`. Replace first asks `confirm("Replace labels?")` (Cancel changes nothing) and uses `mergeClasses([], incoming)`. Both build a new store (Merge: a shallow copy of the current one) and list, `putTile` each window's `mergeTile` of the new store's tile and the non-zero seed, and swap them in only on success. Otherwise nothing changes and ui shows "Label limit reached (256 tiles of 256 x 256 px). Nothing was seeded." on `"full"`, "Too many classes (max 255). Nothing was seeded." on `"too many"`, or "No labels to seed here." when N = 0. Success shows "Seeded N pixels in K classes.", N being the pixels the seed labelled (in Merge, only previously unlabelled ones) and K their classes. Seeded labels are ordinary spec 003 labels.
- **Export labels** writes the imagery's whole grid with ADR 0001's writer: tags copied from the imagery, 256x256 tiles (the stored tile, or zeros), GDAL_NODATA "0", and GDAL_METADATA `encodeClasses(list)` listing every class, used or not, so 255 is the 255th class, not nodata. It reads no imagery window; spec 001's size limit applies. Spec 001's classification export is unchanged (classes 0..254, GDAL_NODATA "255"). Export then Import labels (Replace) saves and loads labels exactly; otherwise labels live only in memory.
- **Settled in build.** "Seed" here means an import or a model seed.
  - *Replaced imagery* (spec 003's rule): a seed belongs to the imagery it started on; if another raster opens first, it swaps nothing and shows nothing (success or error), and the new raster's controls are free at once.
  - *Locks:* while a seed or an Export labels run is active on the open imagery, the brush (no strokes, no footprint) and class add, rename and recolour are locked; selecting still works. Export labels is disabled while the paint queue is non-empty and runs one at a time. Import labels, Class map and Seed are disabled while a Train runs (Train already is while they run).
  - *Class map* is a separate "Class map (optional)" file input; it applies to the next import, is cleared after it, and is kept if the Replace confirm is cancelled.
  - *Model names:* Seed from model refuses a model whose class names break spec 003's name rule: "The model's class names must be unique and not empty, with no spaces around them. Nothing was seeded."
  - *Strings:* "Seeding labels..." while a seed runs; "Exporting labels..." then "Labels exported."; bad class-table JSON shows "The class table is invalid: JSON."; the other fields named are table, entries, [i], [i].value, [i].name and [i].colour.
  - *ASCII:* `encodeClasses` writes non-ASCII characters as JSON `\u` escapes, since the TIFF writer refuses non-ASCII text in its ASCII-type tags (ADR 0001).
  - *Inputs:* Seed mode resets to Merge whenever the store is empty. An empty or non-numeric Min. confidence counts as outside 0..1.
- **Test data.** Small class rasters (under 100 KB) over spec 001's EPSG:4326 fixture, in EPSG:32633: values 0, 3, 7 and 255 with GDAL_NODATA 255; the same without GDAL_NODATA; one with `CLASS_ITEM`; a class map; 3-band and 16-bit files for the refusals. Tests generate larger rasters, and imagery with nodata (a block nodata only in band 2, or a Float32 band with NaN), in memory.

## Acceptance criteria
1. `sourceCells`: on equal grids every pixel maps to itself. With an EPSG:4326 dst and an EPSG:32633 src, the `tests/fixtures/crs-points.json` points give the floor of their recorded src coordinates, skipping points within 0.01 px of an edge. Pixels off src give -1, -1.
2. `seedWindows`, checked by brute force over every window of a 3x3-window dst, holds each window with a cell on a src in another CRS; a disjoint src gives [].
3. `parseClasses` accepts a valid table and rejects, naming the field: a non-array; 0 or 256 entries; a value that isn't an integer, is outside 0..255, is duplicated or equals nodata; a name that is empty, duplicated or not a string; a colour that isn't "#rrggbb".
4. With values {0, 3, 7} present and nodata 255, `classesFromValues` gives "Class 0", "Class 3", "Class 7". `seedLut` maps 0, 3, 7 to 1, 2, 3 with values [1, 2, 3] and to 5, 1, 9 with [5, 1, 9], and everything else to 0. `applyLut` maps -1 to 0.
5. `seedFromModel` on spec 001 criterion 7's tile and model with values 1..n: at minProb 0 it equals `predictTile` + 1, with 255 -> 0; with values reversed, each pixel gets values[`predictTile`]. At minProb 0.9, pixels whose max softmax is below 0.9 are 0 and the rest keep their minProb 0 value.
6. `mergeClasses`: with [] it returns the incoming names, values 1..n and palette colours by position where none is given. [A, B] with incoming [B, C] gives [A, B, C], A and B keeping their colours, and values [2, 3]. 254 classes plus 2 new names gives `"too many"`. `mergeTile` keeps every non-zero old pixel and takes the seed elsewhere; undefined old gives the seed.
7. `maskNodata`: a pixel equal to `tile.nodata` in band 2 only, and a NaN pixel in a Float32 band, become 0; with nodata null only NaN is masked; other pixels are unchanged.
8. `putTile` replaces a tile, deletes it when given all zeros, and at `MAX_LABEL_TILES` returns `"full"` for a new key (store unchanged) but still replaces an existing key.
9. `encodeClasses` then `decodeClasses` round-trips names containing `<`, `>`, `&`, `"`, `'` and non-ASCII text; its output is ASCII, and the writer refuses non-ASCII tag text. On a written file, geotiff.js `getGDALMetadata()` returns exactly one dataset item, `GEOAPP_CLASSES`.
10. Export (EPSG:4326 fixture): geotiff.js reads back the imagery's width, height, origin, resolution and GeoKeys, 256x256 tiles and GDAL_NODATA "0"; pixels equal the store, 0 where no tile is stored. With 255 classes, a class-255 pixel reads back as 255 and imports as class 255. Export reads no imagery window (instrumented source).
11. Round trip (e2e, imagery generated with a nodata block in band 2, strokes crossing it): paint three classes, rename one to `Mangrove & <salt>`, recolour one and add an unused class. Export, reopen the imagery accepting spec 003's discard confirm (the store is now empty), and import the export. Every tile is byte-equal per key, no stored pixel is imagery nodata, and the class list (names, colours, order, the unused class included) is identical.
12. Classes (e2e): the `CLASS_ITEM` file takes names and colours from the item; with a class map, it takes the map's names and its unlisted values stay unlabelled. The 0/3/7 file gives "Class 0", "Class 3", "Class 7"; without GDAL_NODATA, 255 becomes a class too. An invalid class map shows the message and changes nothing. The class map input is empty after each import.
13. Resampling and mask (io, brute force, fixtures and generated nodata imagery): each imported pixel is 0 where any imagery band is nodata or NaN, else `seedLut` of the file value at its `sourceCells`. Model seeding gives 0 at those pixels too. After brush strokes across a nodata block (e2e), then a Merge import and a Merge model seed, every imagery-nodata pixel is still unlabelled.
14. Reads (instrumented file and imagery sources): an import's values pass reads no imagery window; its labelling pass reads exactly the imagery windows whose gathered labels are non-zero, once each. Every file read is a 256x256-aligned window of at most 256x256 holding a cell of the current imagery window, read at most once per imagery window per pass. Model seeding reads each imagery window exactly once.
15. Refusals (e2e): the 3-band file, the 16-bit file and a spec 002 fixture (a) AlphaEarth COG show "Label files must be single-band 8-bit GeoTIFFs."; an unsupported CRS shows spec 001's message; a file not overlapping the imagery shows "No labels to seed here." Each changes nothing.
16. Merge, Replace and cap (e2e unless noted): with no labels, Seed mode is disabled and an import shows no confirm; with labels painted it is enabled with Merge selected. A Merge import shows no confirm, keeps every painted pixel's class, labels only unlabelled pixels and appends only new names. Replace shows the confirm: Cancel keeps labels, classes and the chosen class map, OK replaces them. While an import (paused file source) or an export (paused sink) runs, the brush and class edits are locked but selecting works, Train is disabled during the import and Export labels during the export; while a stroke's mask reads are pending (paused imagery source), Import labels, Seed and Export labels are; while a Train runs, Import labels, Class map and Seed are. A raster opened mid-import shows no message and its controls are enabled. A Merge passing 255 classes shows its message and changes nothing. Seeding a 4352x4352 class raster generated in memory onto an equal grid (io) stops with `"full"` in both modes, leaving store and list unchanged, and ui maps `"full"` and `"too many"` to their messages (unit).
17. Seed from model (e2e, EPSG:4326 fixture): Seed is disabled until a model exists. After training on two painted classes, a Replace seed at 0 gives tiles equal to `seedFromModel` then `maskNodata` on every window, and the list equals `model.classes`; a Merge seed keeps the painted pixels and the list. At 0.9 only pixels whose max softmax is at least 0.9 are labelled. 1.5 or an empty value shows the message and disables Seed. A loaded model with duplicate class names shows its refusal and seeds nothing.
18. Edit and retrain (e2e): after an import, a right drag clears the selected class in a seeded area and a left drag paints. Train then meets spec 003 criterion 15's training checks (N = labelled pixels, `model.classes` = list).
19. Privacy (request log): importing, seeding and exporting labels make no network requests.
