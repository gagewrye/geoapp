# 003: Paint-brush labels for local imagery

**Goal:** Label a local GeoTIFF by painting classes onto its pixel grid with a resizable brush, and train spec 001's logistic regression on the painted pixels.

**Status:** Approved (Gage, 2026-10-26; nodata amendment the same day, with spec 004). Clarifications approved 2026-10-27 (Gage); class-name clarification (names are trimmed) approved 2026-10-28 (Gage). **ADRs (Accepted):** 0009 brush only, 0010 sparse label tiles. Followed by specs 004 (seeding, label export) and 005 (AlphaEarth training). Partly shelved by spec 013 (2026-10-28), lapsed: Training, the AOI clause, the AlphaEarth refusal and layer, and criteria 15, 17's training part and 19's Train part. Amended 2026-10-29 (Gage):
- Spec 016: Pan is the default on open and after an import, and the overlays' `raster-opacity` is the Opacity value (default 0.6), shown only while Show labels is on.
- Spec 017: `BRUSH_SIZES` becomes a 1-127 px odd-size slider, and "−"/"+" and `[`/`]` apply `stepBrush`. Criterion 13 holds as written.
- Spec 018 (ADR 0019): each stored tile is drawn as raster-aligned quads (`tileQuads`, `paintLabels`) in place of `overlayIndex`/`paintOverlay`. Hover keeps `footprintRing`, and criterion 6 is met by spec 018 criteria 1 and 2.

Amended by spec 048 (2026-11-01): there is no tile cap (ADR 0033). `MAX_LABEL_TILES` and `brush`'s `"full"` are gone, so Storage's "full" sentence, criterion 4's cap clause and criterion 15's last sentence lapse. Display: at most 256 stored tiles in view have overlays, and every label also shows on the preview-resolution `mask` layer (spec 014), hidden only under overlays.

**Decided (Gage)**, besides what Scope and Rules state: polygon code is deleted, not flagged off (2026-10-26). Train's snapshot copies the stored tiles, at most 16 MiB (ADR 0010); the 500 ms post-erase `contextmenu` guard applies on the map only, not the panel; a model loaded while a Train runs is replaced when that Train finishes (2026-10-27).

## Scope
In: the brush and its hover preview, size controls, Paint and Pan modes, the class list (add, rename, recolour, select), sparse label tiles on the raster grid shown on the map, training on the raster's bands, removing polygon labelling.
Out: saving, loading and exporting labels (spec 004); labelling or training on AlphaEarth (spec 005); undo; flood fill; disc brushes; deleting classes; painting by touch; showing the classified result.

## Interfaces (`core/`)
```ts
const BRUSH_SIZES = [1, 3, 7, 15, 31, 63, 127]; // default 7
const MAX_LABEL_TILES = 256;                     // 16 MiB
type Grid = { width: number; height: number; epsg: number; gt: Affine };
type LabelClass = { name: string; colour: string };  // "#rrggbb"; label value = index + 1
type LabelStore = { width: number; height: number; tiles: Map<string, Uint8Array> };
  // key `${x0},${y0}` of a tileWindows() window; row-major, window-sized; 0 = unlabelled; no all-zero tile kept
type NodataMasks = Map<string, Uint8Array>; // LabelStore keys; pixel i = byte i >> 3, bit i & 7; 1 = imagery nodata
pixelAt(grid: Grid, lon: number, lat: number): [number, number]  // [col,row], floored; normalizes lon; may be off-raster
footprint(dims: Pick<Grid, "width" | "height">, col: number, row: number, side: number): Window | null
footprintRing(grid: Grid, w: Window): [number, number][] // lon/lat TL, TR, BR, BL, TL of w's outer pixel edges
strokeCells(a: [number, number], b: [number, number]): [number, number][] // Bresenham
nodataMask(tile: Tile): Uint8Array
tileKeys(w: Window): string[]                 // keys of the windows w meets, row-major
brush(store: LabelStore, masks: NodataMasks, w: Window, value: number, erase: boolean): "ok" | "full"
keepMasks(store: LabelStore, masks: NodataMasks, w: Window | null): void // deletes masks of tiles neither stored nor met by w
labelWindows(store: LabelStore): Window[]     // row-major
labelSamples(tile: Tile, labels: Uint8Array, bands: number[]): { X: Float32Array; y: Uint8Array }
overlayIndex(w: Window, grid: Grid, maxSide: number): { index: Int32Array; width: number; height: number; corners: [number, number][] }
  // per overlay pixel: index into w's tile, or -1; same axis-aligned Mercator grid and corner order as warpPreview
paintOverlay(index: Int32Array, labels: Uint8Array, colours: string[], rgba: Uint8ClampedArray): void
```
Criteria 1-6 and 18 define these functions' results.

**Rules.**
- **Local imagery** is any raster opened with "Open raster"; one that looks like AlphaEarth (64 bands, Int8, GDAL_NODATA -128) is refused with "This is an AlphaEarth file. Use Open AlphaEarth file." The brush panel shows only while local imagery is open; AlphaEarth data neither enables it nor touches labels. Opening another raster discards the labels, after `confirm("Discard labels?")` if any are painted (Cancel keeps everything). A Train or raster open that finishes after another raster opened is dropped: no model, message or error. Spec 002's AOI tool switches the brush to Pan (ADR 0009).
- **Hover.** In Paint mode, a mouse or pen over the map shows `footprintRing` of the clipped footprint as one GeoJSON feature (selected colour, fill-opacity 0.4, outlined). It covers the whole footprint, nodata included, reads and changes nothing, and shows whenever the footprint overlaps the raster, even from just off its edge, but not off the globe (`isPointOnMapSurface`) or over the panel.
- **Strokes.** Button 0 starts a paint stroke, button 2 an erase stroke; other buttons, and presses mid-stroke, are ignored. Each position applies `brush` at every cell of `strokeCells(previous, current)`; a position off the globe lifts the brush (no interpolation across the gap). A stroke ends on pointerup anywhere, pointercancel, window blur, or a move with no button held. Paint overwrites any class; erase clears only the selected class. `contextmenu` is prevented on the map while local imagery is open, which covers the 500 ms after an erase stroke (Windows fires it on release), and never on the panel, so text fields keep copy and paste.
- **Modes.** Paint (the default on open) and Pan. Holding Space acts as Pan, except on a focused text input, textarea, select or contenteditable, or on a button or other input that keyboard focused (it matched `:focus-visible` when focus arrived; a pointer press clears that). Pan is MapLibre's default and shows no footprint. In Paint mode, mouse and pen drags never move the map; wheel, keyboard, navigation control and touch work unchanged; double-click and Shift-drag don't zoom (ADR 0009). Touch never paints. A pen tip paints, its barrel button (button 2) erases, and a hovering pen shows the footprint.
- **Brush.** A square measured in raster pixels at every zoom. "−"/"+" and `[`/`]` step through `BRUSH_SIZES`, stopping at the ends; the panel shows "Brush: 7 px". Keys `1`-`9` select the first nine classes. Shortcuts are ignored in text fields.
- **Storage.** Labels live in memory for the session, on the full-resolution source grid. On `"full"`, nothing changes and ui shows "Label limit reached (256 tiles of 256 x 256 px). Erase elsewhere first." The cap limits labelled area, not samples. The e2e hook `__geoapp.labels` exposes `{ store, classes }`; its writes bypass the brush, so tests write only off imagery nodata.
- **Imagery nodata** is a pixel where any band equals the imagery's GDAL_NODATA or is NaN (spec 001's rule). Paint never labels it. Before a stroke cell applies, `io/` reads, one at a time, the 256x256-aligned imagery window of each tile in `tileKeys` of its footprint that has no mask, and keeps only its `nodataMask`. Cells apply in order once their masks are in, so they queue during reads and apply even after the stroke ends; Train is disabled while any are queued. Opening another raster drops the queue and all masks. After each cell, `keepMasks` runs with its footprint (with null after spec 004 replaces the store), so a window is read again only after its mask is freed. Painting reads imagery only for masks; erase and hover read none. At most 264 masks (8 KiB each, about 2.1 MiB) are held; the cap counts label tiles only.
- **Display.** Each stored tile gets a canvas source from `overlayIndex(w, grid, TILE_SIZE)` (built once and kept, at most 256 KiB) and `paintOverlay`, with nearest resampling and `raster-opacity` 0.6. Layers, bottom to top: AlphaEarth preview, imagery preview, label overlays, hover. A colour change repaints every overlay.
- **Classes.** The list starts as "Class 1" and "Class 2", Class 1 selected; colours cycle through a fixed 10-colour palette. Users add (up to 255), rename, recolour and select. Names are unique and not empty, with no spaces around them (names are trimmed); an empty or duplicate name is refused with "Class names must be unique and not empty." and the old name stays. `model.classes` holds the names in list order.
- **Training** needs painted pixels in at least two classes, else ui shows "Paint at least two classes." Train snapshots the labels at the click (copying the stored tiles), so edits during the run don't affect it, reads each window of the snapshot's `labelWindows` once, applies `labelSamples` on all bands and fits every class in the list. If every painted pixel is nodata, ui shows "No training samples: every painted pixel is nodata." Train is disabled from click to run end, so at most one runs at a time; "Classify and export" works the same way. A model loaded while a Train runs is replaced when that Train finishes.
- **180° and MAX_LAT.** No guard: painting edits clipped pixels, not geometry. `pixelAt` normalizes longitude, so every world copy hits the same pixel; rings and overlay corners use `toLonLat`, as the preview does. An overhanging footprint can label pixels beyond ±`MAX_LAT`; they train but aren't drawn.
- **Polygons removed.** `checkRing`, `toPixelPolygons`, `samplePixels`, `PixelPolygon`, terra-draw's polygon and select modes, and their UI and tests are deleted; README describes the brush. Spec 001 criteria superseded here: 2 (by 10 and 14), 3 (by 1), 5 (by 5), 8's bounding-box part (by 8), 12's polygon check (by 9); 13-15 are removed. The rest hold: 1, 4, 6, 7, 9-11, 16, 8's 256x256 and sink-write limits, 12's globe checks.

## Acceptance criteria
1. `pixelAt`: the `tests/fixtures/crs-points.json` points (EPSG:4326, 3857, 32633) give the floor of their recorded pixel coordinates, skipping points within 0.01 px of an edge; lon ± 360 gives the same pixel. On an EPSG:32660 raster straddling 180°, lon 180.2 and -179.8 give the same pixel. An unsupported EPSG throws.
2. `footprint`: sizes 1, 3 and 7 give a centred size x size window, clipped at raster edges, null when the square misses the raster.
3. `strokeCells` includes both ends, consecutive cells differ by at most 1 in col and in row, and there are max(|Δcol|, |Δrow|) + 1 cells.
4. `brush` (masks for every tile met unless noted): paint overwrites another class, skips masked pixels, creates no tile for a dab wholly on nodata, and throws on a tile met with no mask. Erase (no masks) clears only `value`, never creates a tile, and deletes emptied tiles. A size-7 dab on a tile corner creates 4 tiles. At `MAX_LABEL_TILES`, a dab that would label a pixel in a new tile returns `"full"` and changes nothing; one inside stored tiles, or whose new-tile pixels are all nodata, still applies.
5. `labelSamples`: y = value - 1, skipping 0, nodata and NaN. A store over a 2x2 tile grid gives the same sample multiset as one dense tile.
6. `overlayIndex` + `paintOverlay` (UTM fixture): a labelled pixel lands within 1 overlay pixel of its reference lon/lat; the corners form a Mercator rectangle; labelled pixels get exactly the class colour at alpha 255, others alpha 0.
7. No polygons (e2e): no polygon draw or select control exists. With a local GeoTIFF open, the brush panel shows and a left drag adds no terra-draw feature. With only AlphaEarth data loaded, the panel is hidden and a drag over its preview labels nothing. "Open raster" on a fixture (a) AlphaEarth COG shows the refusal and opens nothing.
8. Reads (instrumented 2048x2048 source): hover and erase read nothing. Painting reads only 256x256-aligned windows, one at a time, of tiles met that have no mask: a stroke back and forth over two stored tiles reads each once; one that leaves a tile it labelled nothing in and returns reads it again. Training reads exactly the stored tiles' windows, once each, each at most 256x256, with sample count = labelled pixels that aren't nodata.
9. Hover (e2e): a buttonless mouse move over the raster shows one feature, its ring equal to `footprintRing` of the clipped footprint at `pixelAt` of the pointer within 1e-6° and filled with the selected colour; the store stays empty. None shows over the panel or where the footprint misses the raster. Just off an edge with the footprint overlapping, the ring is the clipped footprint and a click labels exactly its pixels.
10. Paint and erase (e2e, EPSG:4326 fixture): at zoom 14, a horizontal size-7 left drag labels exactly rows r-3..r+3 from start to end column, also as two moves 300 px apart. At zoom 3, a drag of a few moves labels one 8-connected set containing the first and last footprints. A right drag clears only the selected class. `contextmenu` is `defaultPrevented` on the map, also just after an erase stroke, and never on a class name field, even within 500 ms of one. Centre, zoom, bearing and pitch don't change.
11. Stroke end and pen (e2e): release over the panel, pointercancel, or a `buttons: 0` move (CDP) ends the stroke; later moves label nothing. A CDP `pointerType: "pen"` tip drag paints; a barrel (right) drag erases.
12. Pan and zoom (e2e): in Paint mode the wheel zooms without painting. With Space held a left drag pans without painting; after release it paints. After a mouse click on "+", a Space-held left drag pans and the size is unchanged; after Tab to "+", Space steps the size up and doesn't pan. In Pan mode a left drag pans, a right drag rotates, nothing paints. A double-click in Paint mode keeps the zoom. A one-finger touch drag (CDP) pans, paints nothing and shows no footprint.
13. Brush size (e2e): `]` and "+" step up and stop at 127; `[` and "−" step down and stop at 1; the panel text follows; a size-15 dab labels 15x15 pixels. `[`, `]` or `1` typed in a class name field change neither size nor selected class.
14. Classes (e2e): Class 1 and Class 2 at start, Class 1 selected. Add, rename, recolour and select (click, keys 1-9) work. An empty or duplicate name shows the message and keeps the old name. Recolouring changes overlay and hover colour. Add is disabled at 255 classes.
15. Train (e2e, EPSG:4326 fixture): with two classes painted, `model.classes` equals the list and the message reports N = labelled pixels; with one, the message shows and no model is made. Edits during a run leave N and the model as without them. Train is disabled from click to run end, "Classify and export" during its run; a Train or open finishing after another raster opened changes nothing. Export meets spec 001 criterion 9. With the store filled to `MAX_LABEL_TILES` via the hook, a dab on a new tile shows the limit message.
16. Discard (e2e): with labels painted, opening another raster shows the confirm; Cancel keeps raster and labels, OK opens the new raster with an empty store. With none painted, no confirm.
17. Privacy (request log): painting and training make no network requests.
18. Masks (unit): `nodataMask` sets the bits of a pixel equal to `tile.nodata` in band 2 only and of a NaN pixel in a Float32 band (with nodata null, only the NaN pixel's) and no others; a 5x3 tile gives 2 bytes. `tileKeys` of a window across a tile corner gives 4 keys, row-major. `keepMasks` keeps exactly the masks of stored tiles and of tiles w meets.
19. Nodata (e2e, imagery with a nodata block in band 2 only and a NaN block in a Float32 band): a size-15 drag across each block labels every pixel under its footprints except the block's; a dab inside a block creates no tile; the hover ring there is the full footprint. With the imagery source paused, a drag labels the same pixels once reads resume, even after release, and Train is disabled until then. Train's N equals the labelled pixels and the model equals `fit` on them.
