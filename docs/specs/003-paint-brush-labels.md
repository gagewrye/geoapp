# 003: Paint-brush labels for local imagery

**Goal:** Label a local GeoTIFF by painting classes onto its pixel grid with a resizable brush, and train spec 001's logistic regression on the painted pixels.

**Status:** Approved (Gage, 2026-10-26). Amended at Gage's direction (2026-10-26, with spec 004's approval): the brush never labels imagery nodata (Imagery nodata; criteria 4, 8, 18, 19). **ADRs (Accepted):** 0009, the brush is the only labelling tool; 0010, sparse label tiles. Build order: after spec 002, before spec 004 (label seeding and label GeoTIFF export) and spec 005, which trains on AlphaEarth from these labels. **Clarifications 2026-10-27, awaiting Gage** (from the tester's pass): marked [C1]-[C5] inline.

**Open (for Gage, 2026-10-27):**
- [C5] If Train's snapshot copies the label tiles, peak memory rises by up to 16 MiB while training, beyond ADR 0010's bound. Accept that, or require a snapshot that doesn't copy?
- [C3] Does the 500 ms post-erase `contextmenu` guard also apply over the panel?

**Decided (Gage, 2026-10-26):**
- The brush replaces polygon drawing, and polygon labelling and its code are deleted everywhere, not hidden behind a flag.
- Only local or uploaded imagery is labelled. AlphaEarth is never hand-labelled, and AlphaEarth files are refused in "Open raster".
- Erase clears only the selected class.
- Saving and loading labels is deferred; labels last for the session. Spec 004 (approved 2026-10-26) fills this with "Export labels" and "Import labels" (ADR 0013); this spec still keeps labels in memory only.
- A square brush, sizes 1-127, default 7. Touch doesn't paint.
- At most 256 label tiles (16 MiB), held in memory.
- No undo and no deleting classes in v1.
- Imagery-nodata pixels are never labelled, by any path (amendment above).

## Scope
In: a brush with a hover preview; left button paints (skipping imagery nodata), right button erases; size controls; Paint and Pan modes; a class list (add, rename, recolour, select); labels stored as sparse tiles on the raster grid and shown on the map; training on the raster's own bands; removing polygon labelling.
Out: saving and loading labels, and label GeoTIFF export (spec 004); labelling AlphaEarth; training on AlphaEarth (spec 005); undo; flood fill; disc brushes; deleting classes; painting by touch; showing the classified result.

## Interfaces (`core/`)
```ts
const BRUSH_SIZES = [1, 3, 7, 15, 31, 63, 127]; // odd, so the square centres on the pointer's pixel; default 7
const MAX_LABEL_TILES = 256;                     // 16 MiB (ADR 0010)
type Grid = { width: number; height: number; epsg: number; gt: Affine }; // spec 002's Aoi fits this shape
type LabelClass = { name: string; colour: string };  // "#rrggbb"; label value = list index + 1
type LabelStore = { width: number; height: number; tiles: Map<string, Uint8Array> };
  // key `${x0},${y0}` of a tileWindows() window; row-major, window-sized; 0 = unlabelled; no all-zero tile kept
pixelAt(grid: Grid, lon: number, lat: number): [number, number]  // [col,row] containing the point (floor); normalizes lon; may be off-raster
footprint(dims: Pick<Grid, "width" | "height">, col: number, row: number, side: number): Window | null // centred square, clipped; null if empty
footprintRing(grid: Grid, w: Window): [number, number][]          // lon/lat TL, TR, BR, BL, TL of w's outer pixel edges
strokeCells(a: [number, number], b: [number, number]): [number, number][] // 8-connected Bresenham, both ends included
type NodataMasks = Map<string, Uint8Array>; // LabelStore keys; 1 bit per window pixel, row-major: pixel i = byte i >> 3, bit i & 7; 1 = imagery nodata
nodataMask(tile: Tile): Uint8Array            // ceil(width * height / 8) bytes; bit set where any band equals tile.nodata or is NaN
tileKeys(w: Window): string[]                 // keys of the tileWindows() windows that w meets, row-major
brush(store: LabelStore, masks: NodataMasks, w: Window, value: number, erase: boolean): "ok" | "full"
  // paint sets w's pixels whose mask bit is 0 and throws if a tile w meets has no mask; erase clears pixels equal to value, ignoring masks
keepMasks(store: LabelStore, masks: NodataMasks, w: Window | null): void // deletes masks of tiles neither stored nor met by w
labelWindows(store: LabelStore): Window[]                           // windows of stored tiles, row-major
labelSamples(tile: Tile, labels: Uint8Array, bands: number[]): { X: Float32Array; y: Uint8Array } // y = value-1; skips 0, nodata, NaN
overlayIndex(w: Window, grid: Grid, maxSide: number): { index: Int32Array; width: number; height: number; corners: [number, number][] }
  // per overlay pixel: index into w's tile, or -1; same axis-aligned Mercator grid and corner order as warpPreview
paintOverlay(index: Int32Array, labels: Uint8Array, colours: string[], rgba: Uint8ClampedArray): void // v>0 -> colours[v-1], alpha 255; else 0
```
**Rules.**
- **Local imagery.** *Local imagery* is any raster opened with "Open raster". A file that looks like AlphaEarth (64 bands, Int8, GDAL_NODATA -128) is refused with "This is an AlphaEarth file. Use Open AlphaEarth file." The brush panel is shown only while local imagery is open. Spec 002's AlphaEarth data never enables it. Opening another raster discards the labels, after `confirm("Discard labels?")` if any pixel is labelled; Cancel keeps everything. Fetching or opening AlphaEarth data leaves the labels alone. Choosing spec 002's AOI tool switches the brush to Pan (ADR 0009).
- **Hover.** In Paint mode, a mouse or pen over the map shows `footprintRing` of the clipped `footprint` under the pointer as one GeoJSON feature. It has the selected colour at fill-opacity 0.4, plus an outline, and covers the whole footprint, imagery nodata included, so hovering stays synchronous and reads nothing. Hovering never changes labels. [C2] The footprint is shown whenever it overlaps the raster, even with the pointer just off the edge, so hover always equals what a dab there paints. Nothing is shown when the clipped footprint is empty (null), off the globe (`isPointOnMapSurface`) or over the panel.
- **Strokes.** A left press (button 0) starts a paint stroke, and a right press (button 2) starts an erase stroke. Other buttons, and presses during a stroke, are ignored. Each position applies `brush` at every cell of `strokeCells(previous, current)`. A position off the globe lifts the brush, with no interpolation across the gap. The stroke ends on pointerup anywhere, pointercancel, window blur, or a move that reports no button held. Paint overwrites any class, and erase clears only the selected class. [C3] `contextmenu` is prevented on the map while local imagery is open, and for 500 ms after an erase stroke ends (Windows fires it on release). It isn't prevented on the panel, so text fields keep their copy and paste menu.
- **Pan, zoom, touch and pen.** There are two modes, Paint (the default when a raster opens) and Pan, and holding Space acts as Pan, [C4] unless focus is on a form control (input, textarea, select, button or contenteditable), so keyboard users can still press a focused button. Pan uses MapLibre's defaults and shows no footprint. In Paint mode, mouse and pen drags never move the map. Wheel, keyboard, navigation control and touch gestures work unchanged. Double-click and Shift-drag don't zoom (ADR 0009). Touch never paints. A pen tip paints, its barrel button (button 2) erases, and a hovering pen shows the footprint.
- **Brush.** The brush is a square measured in raster pixels at every zoom, so a stroke labels the same pixels at any zoom, and zooming out doesn't make one dab cover thousands of pixels. "−"/"+" and `[`/`]` step through `BRUSH_SIZES` and stop at either end. The panel shows "Brush: 7 px". Keys `1`-`9` select the first nine classes. Shortcuts are ignored while focus is in a text field.
- **Storage.** Labels live on the full-resolution source grid, never on the preview, and only in memory for the session. A tile is created by the first paint that labels one of its pixels and deleted when its last label is erased. Painting reads imagery only to build nodata masks (below). When `brush` returns `"full"`, nothing changes and ui shows "Label limit reached (256 tiles of 256 x 256 px). Erase elsewhere first." This caps the labelled area, not the training samples. The e2e hook `__geoapp.labels` exposes `{ store, classes }`; writes through it bypass the brush, so tests make them only off imagery nodata.
- **Imagery nodata.** A pixel is imagery nodata when any band equals the imagery's GDAL_NODATA or is NaN (spec 001's rule over all bands, as in Training and spec 004). Paint never labels it. Before a stroke cell is applied, every tile in `tileKeys` of its footprint needs a mask: for each missing one, `io/` reads that tile's 256x256-aligned imagery window, one at a time, stores `nodataMask` of it in `masks` and drops the window. Cells apply in order once their masks are in, so positions queue during reads and still apply after the stroke ends. While the queue is non-empty, Train is disabled. Opening another raster drops the queue and all masks. After each cell, `keepMasks` runs with that cell's footprint, and after spec 004 replaces the store it runs with null, so a window is read again only after its mask is freed. Erase and hover read nothing. A mask is 8 KiB, and at most 264 are held (256 stored tiles, plus 4 each for the last and next footprint, since a footprint of at most 127 px meets at most 4 tiles): about 2.1 MiB on top of the 16 MiB of labels. The cap still counts label tiles only.
- **Display.** Each stored tile gets its own canvas source, built with `overlayIndex(w, grid, TILE_SIZE)` and `paintOverlay` and drawn with nearest resampling and `raster-opacity` 0.6. The index is built once per tile and kept with it, [C1] at most 256 KiB per tile (ADR 0010 counts it). Layers from bottom to top: spec 002's AlphaEarth preview, the imagery preview, label overlays, hover. A colour change repaints every overlay.
- **Classes.** The list starts as "Class 1" and "Class 2", with Class 1 selected. Colours cycle through a fixed 10-colour palette. Users can add classes (Add is disabled at 255), rename, recolour and select. A name that is empty or duplicated is refused with "Class names must be unique and not empty." and the old name stays. `model.classes` holds the names in list order. `Model` is spec 001's; spec 005 adds optional tags.
- **Training.** Training needs painted pixels in at least two classes, otherwise ui shows "Paint at least two classes." [C5] Train uses a snapshot of the labels taken when it's clicked, and paints or erases made while it trains don't affect that model. It reads each window of the snapshot's `labelWindows` once, applies `labelSamples` on all bands, and fits every class in the list. If every painted pixel is nodata, ui shows "No training samples: every painted pixel is nodata."
- **180° and MAX_LAT.** No guard is needed, because painting edits clipped pixels and creates no geometry. `pixelAt` normalizes longitude, so every world copy hits the same pixel. Rings and overlay corners use `toLonLat`, as the preview does. Pixels beyond ±`MAX_LAT` can be labelled by an overhanging footprint. They train normally but aren't drawn.
- **Polygons removed.** Delete `checkRing`, `toPixelPolygons`, `samplePixels`, `PixelPolygon`, terra-draw's polygon and select modes, and their UI and tests. Rewrite README's polygon steps and limits for the brush. Spec 001 criteria that still hold: 1, 4, 6, 7, 9-11 and 16, plus criterion 8's 256x256 and sink-write limits and criterion 12's globe checks. Superseded criteria: 2 (by 10 and 14 here), 3 (by 1), 5 (by 5), criterion 8's bounding-box part (by 8) and criterion 12's polygon check (by 9). Criteria 13-15 are removed.

## Acceptance criteria
1. `pixelAt`: spec 001's reference points (`tests/fixtures/crs-points.json`: EPSG:4326, 3857, 32633) give the floor of their recorded pixel coordinates, skipping points within 0.01 px of an edge. lon ± 360 gives the same pixel. On an EPSG:32660 raster that straddles 180°, lon 180.2 and -179.8 give the same pixel. An unsupported EPSG throws.
2. `footprint`: for sizes 1, 3 and 7 the window is size x size and centred. It is clipped at raster edges, and it is null when the square misses the raster.
3. `strokeCells`: it includes both ends, consecutive cells differ by at most 1 in col and in row, and it has max(|Δcol|, |Δrow|) + 1 cells.
4. `brush` (masks given for every tile met unless noted): paint overwrites another class, leaves pixels whose mask bit is set unchanged, and creates no tile for a dab wholly on nodata. Paint throws when a tile it meets has no mask. Erase ignores masks (none given), clears only `value`, never creates a tile, and deletes a tile once it is empty. A size-7 dab on a tile corner creates 4 tiles. At `MAX_LABEL_TILES`, a dab that would label a pixel in a new tile returns `"full"` and changes nothing, while a dab inside stored tiles, or one whose pixels in new tiles are all nodata, still applies.
5. `labelSamples`: y = value - 1, and 0, nodata and NaN are skipped. A store spanning a 2x2 tile grid gives the same multiset of samples as one dense tile.
6. `overlayIndex` + `paintOverlay`: on a UTM fixture, a labelled pixel lands within 1 overlay pixel of its reference lon/lat, and the corners form a Mercator rectangle. Labelled pixels get exactly the class colour with alpha 255, and all others get alpha 0.
7. No polygons (e2e): there is no polygon draw or select control. With a local GeoTIFF open, the brush panel shows and a left drag adds no terra-draw feature. With only spec 002 AlphaEarth data loaded, the brush panel is hidden and a drag over its preview labels nothing. "Open raster" on a fixture (a) AlphaEarth COG shows the refusal and opens nothing.
8. Reads (instrumented 2048x2048 source): hovering and erasing read no window. Painting reads only 256x256-aligned windows, one at a time, each of a tile a footprint meets that has no mask: a stroke back and forth over two stored tiles reads each once, and a stroke that leaves a tile it labelled nothing in and comes back reads it again. Training reads exactly the stored tiles' windows, once each and each at most 256x256, and its sample count equals the labelled pixels that aren't nodata.
9. Hover (e2e): a mouse moved with no button over the raster shows one hover feature. Its ring equals `footprintRing` of the clipped footprint at `pixelAt` of the pointer within 1e-6°, its fill is the selected colour, and the store stays empty. Over the panel, or where the footprint misses the raster, there is none. [C2] With the pointer just off an edge and the footprint overlapping the raster, the ring is the clipped footprint and a click labels exactly its pixels.
10. Paint and erase (e2e, EPSG:4326 fixture): at zoom 14, a horizontal size-7 left drag labels exactly rows r-3..r+3 from the start column to the end column, including a drag made of two moves 300 px apart. At zoom 3, a drag of a few moves labels one 8-connected set that contains the first and last footprints. A right drag clears the selected class and leaves other classes. `contextmenu` has `defaultPrevented` set on the map, [C3] and not on a class name field more than 500 ms after any erase stroke. Centre, zoom, bearing and pitch are unchanged.
11. Stroke end and pen (e2e): releasing over the panel, a pointercancel, or a move with `buttons: 0` (CDP) ends the stroke, and later moves label nothing. With CDP `pointerType: "pen"`, a tip drag paints and a barrel (right) drag erases.
12. Pan and zoom (e2e): in Paint mode the wheel zooms and paints nothing. With Space held, a left drag pans and paints nothing, and once Space is released a left drag paints. [C4] With focus on the "+" button, Space steps the brush size up and doesn't act as Pan. In Pan mode, a left drag pans, a right drag rotates, and nothing is painted. A double-click in Paint mode leaves zoom unchanged. A one-finger touch drag (CDP) pans, paints nothing and shows no footprint.
13. Brush size (e2e): `]` and "+" step up and stop at 127, and `[` and "−" step down and stop at 1. The panel text follows each step, and a size-15 dab labels 15x15 pixels. Typing `[`, `]` or `1` in a class name field changes neither the size nor the selected class.
14. Classes (e2e): the list starts as Class 1 and Class 2, with Class 1 selected. Add, rename, recolour and select (by click and by keys 1-9) work. An empty or duplicate name shows the message and keeps the old name. Recolouring changes the overlay and the hover colour. Add is disabled at 255 classes.
15. Train (e2e, EPSG:4326 fixture): after painting two classes, `model.classes` equals the list, and the message reports N pixels, where N is the number of labelled pixels. With only one class painted, the message appears and no model is made. [C5] Painting and erasing while training runs leaves N and the model equal to a run without those edits. Export meets spec 001 criterion 9. With the store filled to `MAX_LABEL_TILES` through the hook, a dab on a new tile shows the limit message.
16. Discard (e2e): opening another raster with labels painted shows the confirm. Cancel keeps the raster and labels, and OK opens the new raster with an empty store. With no labels painted, no confirm is shown.
17. Privacy (request log): painting and training make no network requests.
18. Masks (unit): `nodataMask` sets the bit of a pixel equal to `tile.nodata` in band 2 only and of a NaN pixel in a Float32 band; with nodata null only NaN is set; all other bits are 0, and a 5x3 tile gives 2 bytes. `tileKeys` of a window across a tile corner gives 4 keys, row-major. `keepMasks` keeps exactly the masks of stored tiles and of tiles w meets.
19. Nodata (e2e, imagery generated with a nodata block in band 2 only and a NaN block in a Float32 band): a size-15 drag across each block labels every pixel under its footprints except the block's, and a dab inside a block creates no tile. The hover ring over a block is the full footprint. With the imagery source paused, a drag labels the same pixels once reads resume, even after release, and Train is disabled until then. Train's N equals the labelled pixels and the model equals `fit` on them (training is unchanged).
