# Geoplatform

Label a local GeoTIFF in your browser. Paint class labels on it with a brush, seed them from an existing class raster, then export them as a label GeoTIFF. Your files and labels never leave your device: the app fetches only its own static files.

## Set up
1. **Install Node.js 22.12 or later** (it includes npm). Get the LTS installer from https://nodejs.org, or:
   - Windows: `winget install OpenJS.NodeJS.LTS`
   - macOS: `brew install node`
   - Linux: use your distribution's packages, or https://nodejs.org/en/download

   Open a new terminal, then check: `node --version`.
2. **Get the code and its packages:**
   ```
   git clone https://github.com/gagewrye/geoapp.git
   cd geoapp
   npm install
   ```
3. **Run it:** `npm run dev`, then open http://localhost:5173 in a Chromium-based browser (Chrome or Edge). Other browsers work, but download exports instead of offering a Save dialog. Press Ctrl+C in the terminal to stop.

If the page shows "Failed to fetch dynamically imported module", stop the server, run `npm run dev -- --force`, and reload the page.

## Use it
The globe shows a bundled, low-resolution Natural Earth shaded relief to help you find your way (public domain; `src/map/basemap.NOTICE.md`). It is one static file, the same for every view. The wheel zooms about the centre of the map, a middle-button drag pans, and holding W/A/S/D pans smoothly (not while typing in a field).
1. **Open GeoTIFF**: pick a GeoTIFF or COG in EPSG:4326, EPSG:3857 or WGS84 UTM (326xx/327xx). A bar shows progress while the preview of bands 1-3 (or band 1 as greyscale) is built; it then appears on the globe, which flattens to Mercator from zoom 12. From zoom 12 the basemap stops drawing, since it would only be a blur there, so the ground outside the raster is plain navy. Large files take a while; a file with overviews opens much faster. When you stop zooming or panning, the view fills in at full resolution, in the preview's colours. Coarser zooms use the file's overviews (add them with `gdaladdo` or `gdal_translate -of COG`); without overviews, zooms coarser than 4 source pixels per screen pixel show the preview. Files stored in blocks over 16 MiB (such as large single-strip files) show the preview only. If part of the file can't be read, the app says so and the preview stays. Opening another raster discards your labels, after asking, stops the previous preview, and starts in **Pan** mode. **Paint** is available once the preview shows. Once a raster is open, the top bar holds the file actions, the strip on the left the tools and brush size, and the panel on the right the classes and label display. `\` hides both side columns so the map gets the full width (kept across reloads), and `Home` or the ⌂ button under the zoom buttons zooms back to the raster. `?`, or the **?** button at the right of the top bar, lists every shortcut, and each tool button shows its key on hover.
2. **Label** with the brush: choose **Paint**. In **Paint** mode a left drag paints the selected class over any other, and a right drag erases the selected class only. **Erase** mode (for trackpads) erases the selected class with a left drag too, and shows a dashed footprint. Keys `B`, `E` and `P` (or Escape) choose Paint, Erase and Pan; one pressed mid-stroke applies when the stroke ends. The square brush is sized in raster pixels at every zoom, 1 to 127 (odd sizes, default 7): drag its slider, or halve and double it with **−**/**+** or `[`/`]`. **Pan** mode, or holding Space, moves the map with a left drag; the wheel, middle drag, keyboard, zoom buttons and touch always do. A pen's tip paints and its barrel button erases; touch never paints. Each class row shows its key (`1`-`9` pick the first nine classes), its colour and its name; click a row to pick it, the colour square to recolour it, and **✎** or a double-click on the name to rename it (Enter keeps the new name, Escape cancels). **Add class** adds one, up to 255. Alt+click a labelled pixel, or press `I` while pointing at one, to pick its class; the tool stays as it was. **Undo** or Ctrl+Z (Cmd+Z on macOS) reverts your latest strokes, up to 50 (32 MiB of history, shared with Redo); **Redo**, Ctrl+Shift+Z (Cmd+Shift+Z on macOS) or Ctrl+Y puts undone strokes back until you paint again. Class edits, imports and opening a raster can't be undone. The brush never labels imagery nodata (a pixel where any band is nodata or NaN, or whose alpha band is 0). To find it, the app reads the whole file once in the background after it opens, while the view is idle, so expect disk and CPU use for a while on large files. Pixels with alpha 0 also show as transparent, and any other alpha value shows as opaque. Under **Labels**, clear **Show** (H) to see the imagery alone; this selects **Pan**, and choosing **Paint**, **Erase** or **Smart select** shows the labels again. Use the opacity slider beside it to set how strongly labels show over the imagery (default 60%; a reload resets it unless you restore saved labels). Hold `` ` `` (the key left of `1`) to glance at the imagery: the labels hide while it is held, nothing paints, and your tool stays.
3. **Smart select** (`M`, or the ⌖ button) outlines a region for you, with a SAM 2.1 model running on your GPU, in Chromium-based browsers with WebGPU (otherwise the button is off and says why). The first use downloads the 80 MB model once, after asking; later sessions load it from the browser's cache. Click a field, building or other region to preview its mask in the selected class colour; click more to add to it, and Shift+click to exclude a part. The model sees a 1024 x 1024 px window around your first click, in the preview's colours, so a larger object is filled in parts. **Enter** or **✓** fills the mask with the selected class, over other classes and never on imagery nodata, as one step Undo reverts; Escape or a right click discards the mask (a right click never leaves Smart), and a second Escape selects **Pan**. A left drag pans, as in **Pan** mode.
4. **Import labels** to seed them instead of painting them all, then correct them with the brush: a single-band 8-bit GeoTIFF of class values (from another tool, a model run elsewhere, or **Export labels**), resampled onto the imagery by nearest pixel centre. Its classes come from the file's own class table (an **Export labels** file has one), and "Class v" for each value the table doesn't name; a bad table never stops the import, and the message names what it ignored. The file's GDAL_NODATA value stays unlabelled. Afterwards, **Apply class map** renames and recolours the imported classes from a JSON matched by file value (`[{ "value": 3, "name": "Water", "colour": "#1f77b4" }, ...]`); values it doesn't list keep their class, and your painting is untouched. The file becomes a mask of any size under your edits: it shows at preview resolution, and a tile you paint or erase is copied from it at full resolution (Undo shows the mask again). Keep the file unchanged on disk while you work; the app reads it again when you edit or export. An import replaces your labels and classes (after asking, if you have any) and then selects **Pan**. While it runs, a bar shows its progress and your current labels leave the map; **Cancel**, a failed import or a file with no labels here brings them back unchanged, with their Undo history. Imported labels never land on imagery nodata.
5. **Export labels** saves the labels (your edits over the mask) and class list as a GeoTIFF on the imagery grid (0 = unlabelled), which **Import labels** loads back exactly. Chromium opens a Save dialog. Other browsers download the file.

Labels are kept in this browser as you work, and still never leave your device. They save about 2 s after your last change and when the tab is hidden; the status bar at the bottom shows when they last saved (with the cursor's position and pixel, the zoom, the brush and the app's messages; errors in red), and the browser asks before you leave with unsaved labels. Open the same file again (even renamed) to be offered them back. An imported mask is copied into the browser's storage too, using about as much disk as the file. A failed save is retried every 30 s; when the browser's storage is full the mask copy is skipped, so a restore then asks you to import the mask again. A saved session goes when you decline the restore, or when it is the oldest of more than 8. Undo history isn't saved.

v1 limits: labels beyond ±85.05° latitude are kept and exported but aren't drawn. EPSG:4326/3857 rasters crossing 180° are refused. Output is capped at 4 GiB (classic TIFF).

## Develop
After **Set up**:
```
npm run check        # lint + typecheck + unit tests (Vitest)
npx playwright install chromium
npm run e2e          # builds, serves on :4173, runs Playwright (without the @probe tests)
npm run e2e:probe    # the slow flicker probe (spec 045)
npm run fetch-model  # Smart select's weights (78 MB, kept out of git) into public/models/; run it before dev or a deploy
```
Smart select runs SAM 2.1 Hiera Tiny (Meta, Apache-2.0; its licence ships with the weights in `public/models/sam2.1-hiera-tiny/LICENSE`) with onnxruntime-web (Microsoft, MIT). The tests use a fake model.
`shelf/` holds shelved code that the app doesn't use and `npm run check` doesn't see (ADR 0017; see `shelf/README.md`).
Layout and rules: see `CLAUDE.md`. Features are specified in `docs/specs/` and decisions in `docs/adr/`.
